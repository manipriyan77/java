(OOP)
=========
Object-Oriented Programming (OOP) is a paradigm centered around objects. It focuses on using classes and objects to 
model real-world entities and their interactions. The key concepts of OOP include classes, objects, inheritance, e
ncapsulation, polymorphism, and abstraction .

Encapsulation:
=============
Encapsulation is the process of bundling data (attributes) and methods (behaviors) into a single unit, or class. 
It helps in protecting the data from outside interference and misuse by specifying which classes can access which members .

In software design, encapsulation is analogized to the way a capsule holds medicine together and protects it from 
the external environment .



Constructors
============
A constructor is a special method invoked when an object is instantiated. It has the same name as the class and does not
have a return type. Constructors are used for initializing an object's state

Key Features of Constructors
===========================
Same Name as Class: A constructor must have the same name as its class.
No Return Type: Constructors do not have a return type, not even void.
Automatic Invocation: They are automatically called when an object of a class is created




ACCESS MODIFIERS
================
PUBLIC: Anyone can able to access
PROTECTED: Anyone within the same package/folder + child class outside the package
DEFAULT: Anyone within the same package/folder
PRIVATE: Anyone within the same class only
